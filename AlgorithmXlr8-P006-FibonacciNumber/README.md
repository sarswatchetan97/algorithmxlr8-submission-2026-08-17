# Fibonacci Number

**Difficulty:** `Easy`

## Problem

The Fibonacci numbers form a sequence where each number is the sum of the two preceding ones, starting from 0 and 1:

F(0) = 0, F(1) = 1, F(n) = F(n - 1) + F(n - 2) for n > 1.

Read an integer n from standard input, and print F(n).

## Examples

### Example 1

**Input**
```
2
```
**Output**
```
1
```

### Example 2

**Input**
```
3
```
**Output**
```
2
```

### Example 3

**Input**
```
4
```
**Output**
```
3
```
